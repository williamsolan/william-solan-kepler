Project 1

TLM Website Redesign

The TLM Website Redesign is a streamlined and visually compelling front-end project designed to enhance user experience while staying true to The Last Mile’s brand identity. Using HTML, CSS, Bootstrap, and Font Awesome, the site ensures clean structuring, responsive styling, dynamic interactivity, and intuitive iconography for seamless navigation. A carefully selected color palette, featuring gold, black, and electric blue, reinforces the brand’s energy, while an original Affinity Designer-crafted logo symbolizes determination and progress. The result is an accessible, engaging website where users can explore TLM’s mission, available courses, and direct contact options with ease.

Technologies used include:

  • HTML
  • CSS
  • Bootstrap
  • Font Awesome

Project 2

Testimonial

This LMS project for The Last Mile required creating a webpage that accurately replicated both mobile (375px) and desktop (1440px) designs using only provided example images as references. Every effort was made to meet all requirements, including refining HTML and CSS for clarity and organization. While following instructions, unnecessary files were deleted, including the designs folder. Some unexpected discrepancies emerged, such as the suggested Arial font differing from the design examples and the favicon icon not appearing in them. In response, the favicon was removed, and Arial was retained as the most comparable available font choice.

Technologies used include:

  • HTML
  • CSS
